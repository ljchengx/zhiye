# 计算练习册

面向小学低年级的月度计算练习：100 以内加减与九九表，每份一张 A4 双面、共 25 题。
每个题块只练一件事，题型在连续几份之间轮换，五天之内不会连着做同一类题。

## 适用年龄

面向小学低年级（建议 6 岁以上），对应已经认识两位数、开始学加减竖式与九九表的阶段。

幼儿园中大班不适用：他们的数范围通常在 10 以内，还不需要两位数的进位与退位，
也不适合一次写 25 道题。中大班建议改用实物操作与游戏。

## 题型

| 题型 | 纸面 | 练什么 |
| --- | --- | --- |
| 直接写出得数 | `38 + 27 = ____` | 加减口算与九九表 |
| 列式计算 | 位值对齐的竖式，横线下留答题区 | 进位、退位与乘法竖式 |
| 填空 | `____ + 27 = 63`、`9 × ____ = 54` | 逆运算与数感 |
| 找错改正 | 印出错式，下面留一条改正线 | 检查与纠错 |
| 连加连减 | `38 + 27 - 15 = ____` | 两步运算与顺序 |
| 算完检查 | `36 + 27 = 63`，再填 `63 - 36 = ____` | 加减互逆 |
| 比大小 | `27 + 38 ○ 30 + 35` 填 `>` `<` `=` | 不算出结果判断关系 |
| 一题多解 | `38 + 27 = ____`，留两行写不同算法 | 凑整与分位 |
| 填符号 | `38 ____ 27 = 65` | 四种运算的意义 |
| 凑整再算 | `38 + 27 = 40 + ____` | 加法补偿、和不变 |
| 进几出几 | 两行表格，进的数全给、出的数只示范一个 | 输入输出规律 |
| 数线移动 | 数线上两段箭头，终点留空 | 位值与数轴 |
| 数的拆分 | `58 = ____ + ____` | 数的组成 |
| 应用题 | 一行文字加列式横线 | 一步加减乘除，**每份固定一节** |

## 每份怎么排

- 每份固定 **25 题**、**4 个题块**：3 块轮换题型 + **1 节生活应用题**（固定在最后）
- 应用题的 12 个场景：添进来、坐车、排队、日期、用掉、看页数、飞走、买东西、成盒、单价、平分、装盒
- 13 种题型排成一条序列，每份取连续 3 个位置：**连续四份的轮换题型互不重复**，四份走完 12 种
- 题量按题型的行高自动分配：题块先各给 2 题，再往「加一题不多占行」的块补，
  到高度上限就停，保证 25 题排得下且不越界
- 正反面按题块高度平均分配，正面两块、反面一到两块，页脚只标「第 N 份 · 正面／反面」

## 数据与约束

- `lib/tools/drill/types.ts` 是题组模型：题型、题块、小题、份；答案与题目分开记录
- 每个题型一个模块（`oral.ts`、`fill.ts`、`vertical.ts`、`chain.ts`、`relations.ts`、
  `checks.ts`、`strategies.ts`、`numberLine.ts`、`inOut.ts`、`word.ts`），
  各自导出生成、验题与纸面文字
- `blocks.ts` 保存各题型的排版设置与轮换序列，`generate.ts` 负责按份生成与换题，
  `layout.ts` 把题组排成毫米坐标的页面
- 加减数值在 0～100，减法不出现负数；乘除只用九九表内的数，除法必定整除
- 封闭题独立验题（填空只有一个解、填符号只有一种符号成立、比大小的符号唯一）；
  开放题（一题多解、数的拆分）只保证题目成立
- 答案只用于验题：`layout.ts` 不读取 `.answer`，测试会检查这一点

## 输出与字体

`layout.ts` 把题组排成 `WorksheetPage`：一个题块一个区域，共享页眉与页脚。
浏览器预览、浏览器打印与 PDF 三端读同一份坐标文档，所以题组不需要额外的渲染分支。

字体沿用 Noto Sans SC 子集（651 个汉字）与 Andika（数字、`× ÷ =` 等符号）。
除号只在 Andika 里，文本分段时与数字一起交给数字字体；页头标签也用字体里已有的说法。
新增中文仍须按原流程重建子集：

```powershell
python scripts/build-number-sense-fonts.py --source "本地字体目录/NotoSansSC-variable.ttf"
```

然后递增 `font-manifest.ts` 版本。构建脚本与字形测试扫描源码全文，注释里的中文同样受约束。

## 验证

- 每个题型 400 组材料独立验题；答案用另一套算法重算
- 每份恰好 25 题、4 块且含一节应用题、连续四份的轮换题型不重复
- 遍历 30 份两面的每个节点：纸面范围、题块范围、正文 ≥14pt、图注 ≥10pt
- 源码字形扫描覆盖 `lib/tools/drill`、绘图、排版、PDF 与渲染组件
- 端到端：份数选择、正反面切换、换题、导出取消与重试、打印两页、三种视口
