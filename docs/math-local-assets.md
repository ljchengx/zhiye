# 数学练习本地素材

数学练习支持从用户主动选择的本地文件夹读取角色图片。浏览器只在当前页面创建本地对象 URL，图片不会上传到服务器，也不会写入项目目录。

默认轮换使用已有的马里奥、路易吉、小库巴、害羞幽灵和数字积木 1～20，共 24 个角色；第 1 份使用马里奥。角色只作纸面陪伴图示，题干与数量关系不依赖角色身份。在数感工作区展开「更多设置」，点击「选择角色文件夹」可替换对应角色；话题和题目材料不受素材替换影响。

推荐目录结构：

```text
数学角色素材/
└─ characters/
   ├─ mario.png
   ├─ luigi.png
   ├─ bowser-jr.png
   ├─ boo.png
   ├─ number-block-1.png
   └─ number-block-20.png
```

支持 `png` 和 `jpg/jpeg`，英文文件名不区分大小写，也接受“马里奥／马力欧”“路易吉／路易基”“小库巴”“害羞幽灵／嘘嘘鬼”等中文文件名。数字积木支持 `number-block-1`～`number-block-20`、`nb1`～`nb20`；在 `numberblocks` 或“数字积木”目录内，还接受 `1.png`～`20.png`。无法匹配的图片会被忽略。同名文件同时存在时，优先使用 `characters` 路径下的文件。

选择文件夹后，A4 预览、浏览器打印和 PDF Worker 都使用本地图片。清除本地素材或刷新页面后，会恢复使用内置兜底资源；页面刷新不会保留文件夹授权，需要再次选择。

导出仅处理所选页面用到的角色。JPEG 和 PNG 均按预览方向转正后，以最长边不超过 1024 像素的 PNG 嵌入 PDF，保留透明背景，以保持打印方向并控制占用。

只应加载自己拥有或已获得使用授权的素材。

内置的 `number-block-1.png` 至 `number-block-20.png` 来自 Numberblocks Wiki 角色页（Fandom 静态资源）。这些页面没有提供可再分发授权声明，素材版权归原权利人所有，正式公开发布或用于商业用途前需要确认授权。
