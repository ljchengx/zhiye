# 月度图画数感活动

入口 `/kids/math-worksheet`。面向已熟练掌握百以内加减的小学低年级孩子（建议 6 岁以上），每份 A4 双面，每面一幅可圈、连、画、填的完整材料图。默认 30 份，可按真实年月生成 28～31 份；没有阶段递进，可任意跳选。

## 适用年龄

面向小学低年级，建议 6 岁以上、已熟练掌握 100 以内加减。活动涉及两位数加减、位值与拆合、100 以内数线与区间判断，每面题面以文字表述，需要孩子能独立读题。

幼儿园中班和大班的数范围通常在 10 以内，大班可延伸到 20 以内数的认识；《3-6 岁儿童学习与发展指南》对 5～6 岁的要求是借助实际情境和操作理解加和减的实际意义、进行 10 以内的加减运算。把这套纸直接交给中大班，会同时超出数范围、识字量和认知操作三方面，建议改用实物操作与游戏，或等进入小学低年级后再用。

## 内容编排

内容库包含 46 种活动，每种有两个操作版本。整月先让全部活动各出现一次，再选择部分活动重访；重访改变操作、条件或推理方向，不只更换数字。同一种活动最多出现两次，两次至少相隔 7 份。正反面的主要动作和能力方向不同，每份至少一面属于数量核心活动，避免整份都是图形或位置任务。

| 公交车的变化 | 用上下车变化找最后人数 | 从到站人数倒推出发人数 |
| 日历小计划 | 跨行寻找约定日期 | 从约定日期向前寻找开始日期 |
| 彩带接起来 | 区分首尾拼接与重叠拼接 | 根据目标长度安排重叠位置 |
| 数卡小火车 | 按相邻数的关系找缺卡 | 放宽为从小到大，寻找不同可能 |

| 两条数线 | 两条范围不同的数线走到同一格，各表示几 | 把两张数卡画到两条数线的同一格上 |
| 离整十多远 | 圈出离 50 最近、离 100 最近的数卡 | 按离 100 由近到远排好，圈出最接近整十的那张 |

| 哪个结果不合理 | 只用整十想一想，圈掉不可能的结果 | 看算式圈出合理的得数，改一个数字让另一个也合理 |
| 图和算式 | 圈出能说清这幅图的算式，可以多于一个 | 给一个算式圈出能说清它的图，再改一个数字 |
| 比 60 大又比 80 小 | 圈出落在区间里的数卡和最接近 70 的，再写一个 | 换掉四张数卡里的一张，让区间里正好有两个数 |

| 谁的猜数更准 | 两个猜数，圈出更接近结果的那个 | 判断一个猜数猜多了还是猜少了 |
| 凑整十再算 | 把一个数补成整十，填出好算的算式 | 圈出结果一样大的那组 |
| 先减整十 | 把减数看成整十，填出好算的算式 | 圈出结果和原式一样的算式 |
| 哪边结果大 | 不用算出结果，圈出哪边结果大 | 填出两边相差多少 |
| 算完检查 | 算出结果，再用另一个算式检查 | 圈出能检查这个结果的算式 |

纸面不预设乘除或分数，不含天平、跷跷板、答案页和解析入口。保留既有动画人物与本地素材替换。能力标签里的“比较测量”包含精确数格、比较余量与猜数判断，其中真正要估的是结果在哪一段、谁的猜数更准、先猜再数和哪个结果不合理四种。

## 数感覆盖

按课程标准里数感的四个要素盘点（同一活动可能落在多个要素下）：

| 要素 | 主要活动 |
| --- | --- |
| 数与数量 | 积木装进十格盒、满盒和散珠、同一个数的多种表示、数线上的小旗、两条数线、离整十多远、比 60 大又比 80 小、数卡小火车、对号找座位、我们想挨着坐 |
| 数量关系 | 点心分一分、停车场挪一挪、拼到整十更好看、谁追上了谁、换一种分法、云后藏着几只鸟、公交车的变化、图和算式、舞会找伙伴 |
| 运算结果的判断 | 结果在哪一段、谁的猜数更准、先猜再数、哪个结果不合理 |
| 简单数量规律 | 花坛里的规律、项链接着穿、数卡小火车 |

计算办法共四种：拼到整十更好看（搬珠子凑整十）、凑整十再算、先减整十、算完检查。它们都要求说出「结果有没有变」，不做纯算式练习。

## 建议使用顺序

生成器不设难度阶段，任何一份都能单独使用。若想按由易到难安排，可以参考：

- 起步，数在 20 以内，以具体操作为主：花园里的发现、舞会找伙伴、项链接着穿、花坛里的规律、点心分一分、拼到整十更好看、数卡小火车、换一种分法、窗上的贴纸、蝴蝶的另一边。
- 进阶，数在 50 以内：积木装进十格盒、同一个数的多种表示、满盒和散珠、数线上的小旗、哪边结果大、凑整十再算、先减整十、云后藏着几只鸟。
- 挑战，数到 100：两条数线、离整十多远、结果在哪一段、先猜再数、谁的猜数更准、哪个结果不合理、小小商店、公交车的变化、图和算式、比 60 大又比 80 小、算完检查、彩带接起来。

## 家长检查要点

纸面不附答案，可以按这几条快速判断孩子是不是真的理解，而不只是填对：

- 守恒类（点心分一分、停车场挪一挪、拼到整十更好看、换一种分法、谁追上了谁）：问一句「东西变多了吗」，能说出总量没变就够了。
- 位值类（积木装进十格盒、满盒和散珠、同一个数的多种表示）：看孩子是不是按「几个十和几个几」说，而不是一个个数。
- 数线类（数线上的小旗、两条数线、离整十多远、比 60 大又比 80 小）：看落点大概对不对，位置比精确值更重要。
- 猜数类（先猜再数、结果在哪一段、谁的猜数更准、哪个结果不合理）：看孩子有没有先用整十估再检查，估得不准没关系。
- 计算办法类（凑整十再算、先减整十、算完检查）：看两处结果对不对得上，以及能不能说出「哪个数添了、哪个数要减掉」。
- 关系类（图和算式、云后藏着几只鸟、公交车的变化、谁追上了谁）：看孩子能不能用自己的话把关系讲一遍。

## 数据与约束

- `types.ts` 保存统一领域类型，活动额外记录 `edition: 0 | 1`。`curriculum.ts` 保存基础活动定义，六组 `activities-*.ts` 分别维护空间、数量、逻辑、数量核心、猜数与计算办法活动的数据、生成与验题。
- `NumberSensePlan.days` 是整月内容唯一来源；每份 `pages` 仅包含正反两个活动。
- `curriculum.ts` 保存活动定义、主要动作、能力标签及月长配置，`generate.ts` 统一编排与去重。
- 保留 `generateDailyWorksheet`、`generateWorksheetPlan`、`regenerateWorksheetDay`、`getExportDays` API。同种子与配置可复现。
- 换题保留该面的活动和操作版本，改变实际材料，避开整月旧内容；整月导出读取最新版本。
- 签名依据实际关系与材料，不把未显示字段、选项排序或同排车位重排视为新题。
- 封闭任务独立验题；开放任务明确约束，保留多种成立的做法。数值和计算中间量在 0～100，减法不出现负数。
- `activities-number.ts`、`activities-estimate.ts`、`activities-strategy.ts` 与对应 `scenes-*.ts` 负责 14 个数量核心活动；`NUMBER_CORE_KINDS` 共 35 种，是编排配额的唯一依据。
- `curriculum.ts` 的 `EDITION_SHIFTS` 映射表记录每种活动重访时换掉的思考方式（方向/条件/表示/开放度），测试据此做语义断言。

## 输出与字体

`layout.ts` 将材料转换为以毫米为单位的 `WorksheetDocument`。`scenes-*.ts` 只读取题目材料和操作版本，不读取内部 `validation`。儿童指令至少 14pt，图注至少 10pt，书写与绘图位置直接贴近材料。

预览和浏览器打印共用 `NumberSensePaper` SVG，PDF Worker 绘制同一份坐标文档。输出按每份正反面排列；本份 2 页、默认整月 60 页，不添加空白背面。正反面实时切换，换题同步提交两面。资源失败保留当前内容并可重试，取消导出释放临时资源。

浏览器与 PDF 共用 Noto Sans SC 常规、粗体及 Andika。本次新增纸面文案全部使用现有中文字体子集已有字形，未重建子集；但将来新增中文仍须按原流程取 NotoSansSC 可变字体源文件执行：

```powershell
python scripts/build-number-sense-fonts.py --source "本地字体目录/NotoSansSC-variable.ttf"
```

然后递增 `font-manifest.ts` 版本。不得用系统字体替代练习纸字体；构建脚本与字形测试扫描源码全文，注释里的中文同样受子集约束。图形通过轮廓、纹理、位置和标签区分，黑白打印仍可作答。纸面允许出现加减算式 `+ − =`，只用于表达关系，不要求算出得数。

## 验证

数学测试遍历 100 种子及 28～31 份计划，检查活动覆盖、每类最多两次、最少 7 份间隔、正反面动作搭配、两版提问、数值范围、复现、真实换题和导出更新；并断言每份至少一面数量核心、数字分布、先猜再数与合理性判断的出现次数、两版变化类型有声明、重写过的活动两版纸面确有差异。新增六组测试用独立枚举、坐标变换、守恒关系与补偿等式验证具体任务，并检查 46 种活动在 28～31 份下的编排容量与纸面边界。

字体与排版测试遍历 6000 张纸，检查边界、字号、资源与答案隔离，并按文字节点角色（body/caption）断言指令不小于 14pt、图注不小于 10pt；浏览器测试检查正反预览、换题、导出、失败重试、取消及 1440／1280／390px 视口。人工检查全部活动的代表页和两版操作，不沿用旧八类场景的排版结论。
