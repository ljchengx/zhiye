# 月度混合数感双面练习重构方案

> 历史方案，旧八活动固定槽位已被“每面一幅完整活动场景”替代。下文保留讨论记录，不作为当前实现要求；当前说明见 [数感模块文档](number-sense.md)。本稿仅为讨论记录，现行内容库已扩至 46 种并补充数位、先猜再数、两条数线、图和算式、结果范围与猜数比较，以及凑整与检查办法，见 number-sense.md。

本方案面向已经熟练计算 100 以内加减的孩子，培养对数量、大小、距离、拆合与变化的理解和感受。孩子可以通过指、圈、连、画、选择、举例和自主构造表达想法，计算作为验证和探索的工具。

**最新组织原则。** 每份是一张 A4 正反面，默认每面四个活动区、每份八个活动。每份混合六类数感能力，内容独立，保持相近的知识要求和提示程度。取消按周安排能力、阶段递进、后期减少提示及跨日先修依赖。份数和日期只用于选择、打印与管理；孩子可以任意抽取一份使用。

每次生成一个月的内容，默认 30 份；选择具体年月时可按该月实际天数生成 28～31 份。30 份对应 30 张双面纸、60 页 PDF。两面均为完整的练习内容，不提供答案、解析或解答入口。

**当前实现需要调整的原因。** 现有程序把六个阶段分别绑定到不同题型，每天一页、四个任务，工作区按一天对应一页读取内容。上一版方案仍包含周主题与学习顺序。此次需要同时调整内容组合、任务验证、双面排版、预览导航与打印导出。

**六类能力作为每份内容的组合依据。**

| 能力 | 内容来源 | 可以观察的表现 |
|---|---|---|
| 数量与结构 | 成组看量、数量重排、同一数量的不同表示 | 利用结构理解数量，区分数量和排列、疏密、占地大小 |
| 大小与距离 | 基准数、数线位置、远近、不同数线范围 | 对数的相对位置和距离有判断 |
| 拆合与基准 | 围绕整十或 25、50、100 组合、拆分与配对 | 灵活理解一个数的组成，找到不同搭配 |
| 变化与关系 | 数量转移、同步变化、整体与部分、总量与差值 | 预判变化，区分哪些量改变、哪些关系保持 |
| 估计与检验 | 确定范围、排除不合理结果、检查说法 | 对结果有预期，能借助简单关系检验判断 |
| 构造与选择 | 按条件造数、接近目标、改条件、举例或反例 | 主动生成例子，比较选择，理解成立条件 |

平均分、余量和等量补偿可以融入这些活动。图形求未知数、聪明格不进入默认固定栏位。每个活动记录一项主要能力，整份覆盖按主要能力计数，附加标签不重复计入覆盖。

**正反面都采用混合内容。** 以下八个位置是一份完整样板的内容组成，后续生成可以调整顺序和表现形式。

| 面 | 活动区 | 内容示例 | 操作或作答方式 |
|---|---|---|---|
| 正面 | 01 数量看一看 | 比较两幅排列不同的点图，判断数量关系 | 圈成便于观察的几组，再作判断 |
| 正面 | 02 数的位置 | 在给定端点的数线上标出数，比较谁离基准更近 | 标点、连线或圈选 |
| 正面 | 03 先估一估 | 判断结果可能在哪个范围，排除不合理候选 | 圈范围或划去不可能的结果 |
| 正面 | 04 数卡搭一搭 | 从数卡中选择符合目标的组合，寻找不同搭配 | 圈选、摆放或填写数卡位置 |
| 背面 | 05 变化看关系 | 一边给另一边一些物品，或两边同时改变，观察总量和差值 | 预判、补图、比较前后关系 |
| 背面 | 06 换一种表示 | 用数量条、点阵、成组表示同一个数量 | 分段、圈组或补画另一种表示 |
| 背面 | 07 判断与修正 | 检查一个说法，举例验证；不成立时修正或给出反例 | 选择判断，画例子或作简短说明 |
| 背面 | 08 我来创造 | 造出符合条件的数、数量组合或变化方法 | 自由构造，允许多种成立方案 |

每面至少覆盖三类主要能力，整份覆盖全部六类。默认八个活动中，同一主要能力最多占两个活动区。每个区块包含一个主任务，最多附一个简短追问；每面至少有一项允许不同成立方案的构造或表示转换活动。整份需要文字说明的任务最多两项，其余使用图形或短动作表达。

例如，数卡活动可以给出 18、19、20、21、22，让孩子选三张组成目标，每张只用一次，并寻找另一种搭配；数线活动可以同时使用 0～100 和 0～50 两条线，观察同一个数的位置。两项活动可分别完成，不依赖对方的答案。

**丰富体现在材料、关系和动作上。** 点图、数线、数量条、数卡、前后对照图和构造区共同组成页面。每个区块都要有清楚的观察材料和作答位置。孩子处理的是数量关系、表示方式或选择条件；只报告一个算式得数不能完成整份活动。

正反面各自可先做，每个活动所需条件、图例和材料都在本区块内给全。默认各份使用相近的难度和提示水平，变化来自组合、图示、数值及关系条件。重复使用某种表示时，不根据份数自动撤去必要图例。

一份双面练习可分两次使用，每面先按约 10～15 分钟试用，并根据样板实际使用情况调整任务量。核心活动纸笔可完成，棋子、积木等作为可选辅助。家长提示放在工作区可展开的位置，以中性追问为主，不包含结论或标准解法。

**模板池支持同水平的多样组合。** 首批为每项能力准备至少四种有实质差别的模板，例如数线定位、比较距离、给位置选数、改变范围；数量活动则包括结构化点图、不同排列比较、数量条与点阵对应、重新圈组。模板可以跨能力复用，但每道活动只指定一个主要目标。

生成顺序为：确定本次份数与固定支持水平，给每份分配六类能力及两个轮换活动，再选择兼容版面的模板，最后生成语义参数、题面与图形。安排与活动编号无难度关联，每份不引用其他日期或其他活动的结果。

月度生成控制模板频率，避免同一个八区组合反复出现。同一能力可以换表示、换条件、换操作；人物名、颜色和微小坐标扰动不构成新内容。重新生成本份或整月时，继续满足完整覆盖和版面约束。有前一份月度计划时，可将其题目签名作为避重输入。

**领域模型以一份双面练习为单位。** 保留 `NumberSensePlan.days` 作为内容唯一来源，以及 `generateDailyWorksheet`、`generateWorksheetPlan` 两个入口名称，迁移时补充月度配置。

- `NumberSensePlan` 保存种子、份数或年月配置与练习列表，长度取实际列表长度。
- `NumberSenseDay` 表示一份独立练习，保存编号、能力覆盖和八个活动。正反面编排引用这些活动，题目数据只保存一次。
- `NumberSenseTask` 保存主要能力、模板编号、操作要求、结构化材料、作答区域要求与内部验证条件，不再固定使用观察／求解／解释／挑战四种槽位。
- `WorksheetPage` 增加稳定页标识、所属练习标识及正反面属性。每份固定产生两张内容页，同一份的两面使用相同练习编号。
- `WorksheetDocument.pages` 按第 1 份正面、第 1 份背面、第 2 份正面、第 2 份背面的顺序排列。份数和页面数分别计算，页面数为选中份数的两倍。

单份换题返回一份活动数据及两张排版页，工作区同时替换这两面。Worker 继续使用请求编号和身份检查处理过期结果，失败时保留当前内容。相同种子和配置产生相同练习；避重历史也作为明确输入。

**开放任务按成立条件验题。**

| 验证类别 | 适用活动 | 验证要求 |
|---|---|---|
| 精确关系 | 数量比较、变化、正误判断 | 关系成立，封闭问题的解与题面条件一致 |
| 范围与位置 | 估量、数线定位、结果范围 | 端点规则明确、比例正确，近似活动有合理接受范围 |
| 条件构造 | 选数、拆合、自主举例 | 枚举有限选择空间，存在满足要求的方案；要求两种时至少存在两种不同方案 |
| 最优化 | 尽量接近、改动最少 | 独立枚举全部候选，接受全部并列最优方案 |
| 观察与表达 | 重排、表示转换、比较方法 | 记录可观察的成立条件和允许的不同思路，进行人工内容审查 |

口头表达和开放绘图不作自动对错判定。内部解、最优组合和观察标准仅用于验证，不进入预览、打印或 PDF。

**数学与内容约束。**

- 所有题面已知数、被要求进行的计算及其中间量保持在 0～100；减法无负数，不依赖乘法口诀或正式乘除算式。
- 点图、成组数量、数线、数量条和前后变化共享结构化数据，题干与图形一致。比例关系与数量对应，作答图不预先填入待求结论。
- 估计活动能够借助给定参照或熟悉关系进行判断，近似活动不强求唯一精确数字。
- 数线明确端点与范围，条件构造明确数字能否重复使用，以及需要多少种不同方案。
- 无序组合按数学语义去重，交换同一组数的顺序不作为新方案；要求不能精确达到目标时，验证确实不存在精确方案。
- 整月判断题正误数量差不超过 1，同类判断连续相同答案不超过三次。题面明确要求找错时，必须存在实际错误和可行修正。
- 对变化或“始终成立”的说法验证其定义域和条件；反例任务确实存在反例，题面不会遗漏关键条件。
- 题目签名包含模板、关系、语义参数及提问目标。一份内禁止同一提问重复，月内去除完全重复活动。
- 每个活动独立可做，必要图例随活动给出。更换任意一份不影响其他份的条件或理解。

**双面排版以每面四个活动区为基准。** 保留 A4 210×297mm、四边 12mm、页头 24mm、页脚 7mm、区块间隔 4mm，页内可用宽度为 186mm。先采用两种四区版式：

| 版式 | 分配方式 | 适合内容 |
|---|---|---|
| 两个通栏＋两个并排区 | 两个通栏行各 70mm；并排行 86mm、每区宽 91mm；行高合计 226mm，加四处间隔、页头及页脚后为 273mm | 数线、点图比较、前后变化使用通栏；短判断和数卡放并排区 |
| 四个组合区 | 两行，每行 115mm、两列各 91mm；加三处间隔、页头及页脚后为 273mm | 数卡、短数线、分组、条件构造等适合较窄空间的活动 |

正反面可以选用不同版式。模板声明最小宽度、所需图形和作答空间；复杂数线、对照图优先使用通栏。排版器选择兼容位置，文字放不下时改写模板或重新生成适配内容，不缩小字号或裁切文字。

儿童题干至少 14pt，主要数字与算式 20～24pt，辅助文字至少 10pt。每区题干尽量控制在两行内，后续条件贴近对应图示。纸面以观察材料、可操作图形和作答空间组织，采用白底、深色文字与少量蓝黄强调。黑白打印通过轮廓、形状、位置和文字区分内容。

页头显示本月第几份以及正面／背面，活动编号从 01 延续到 08。两面内容保持统一的字号、线条和符号规则。角色只在页头作少量陪伴，不占据活动空间。

**预览、打印和导出成对处理。** 工作区使用月度份数选择，不展示学习阶段、周主题或进度路线。默认预览当前份的正反面，手机可切换或连续查看两面，原尺寸放大后允许滚动。

主要操作为打印本份、本份换一套；导出提供本份、自选份数范围、整月。选择范围以整份为单位，保持正反面连续且页面数为偶数。默认 30 份整月导出为 60 页；28、29、31 份分别为 56、58、62 页。

浏览器打印本份产生两张内容页，PDF 使用相同页面顺序。界面提示双面打印选择长边翻转，实际双面设置由打印对话框决定。正反面都包含练习活动，不添加空白背面。预览、打印和 PDF 继续从同一份 `WorksheetDocument` 绘制。

**实施顺序。**

1. **先做完整双面样板。** 制作三份不同混合组合的完整样板，共六页；每份都覆盖六类能力。检查每面内容丰富度、图形用途、作答空间以及整份使用时间。
2. **建设模板池与验证器。** 实现六类能力各至少四种模板及多解、范围、最优选择等验证，建立整份覆盖、重复控制和同水平组合规则。
3. **迁移双面模型与共享排版。** 调整现有课程、类型、生成器和排版器，实现一份八活动、两张内容页。复用已有字体、SVG、PDF 绘图与图片方向处理。
4. **接入月度生成和工作区。** 更新 Worker 返回、双面预览、份数选择、整份换题、浏览器打印和导出范围；保留失败恢复、过期请求拦截和取消能力。
5. **清理旧假设并完成验收。** 移除固定 60 天、六阶段、四题单页、周主题和跨日递进等依赖，更新字体子集、介绍、FAQ、预览图及测试文档。

**内容验收以每份为单位。** 每份覆盖六类主要能力，每面至少三类，默认八个活动区且操作方式有变化；每面至少一项活动允许不同成立方案。任意抽取或倒序使用练习均能独立完成。编号不决定难度或提示程度，书面表达能力不作为数感理解的必要条件。

**工程与数学验收。**

- 至少 100 个种子分别生成 28、29、30、31 份计划，检查每份与每面的能力覆盖、独立性、数值范围、关系成立、开放任务解数量、并列最优、反例、去重及复现。
- 独立枚举有限选择空间，避免直接使用生成器给出的结果作为唯一验证依据。
- 验证单份换题同时更新正反面，整月导出包含最新版本；有历史输入时检查跨月避重。
- 验证份数与页面数分别为 N 和 2N；打印当前份恰好两页，范围及整月导出按正反面配对，无遗漏、错配或空白页。
- 遍历全部页面，检查纸面、活动区、列间距、文字重叠和作答区；人工检查三份完整双面样板、最长题干及黑白输出。
- 浏览器打印与 PDF 的文字、图形位置误差控制在 1mm 内，无答案泄露、缺字或裁切。
- 检查 1440、1280、390px 下的双面浏览、换题、导航和导出，验证字体及素材失败、重试、取消、旋转图片和透明背景。
- 类型检查、相关单元测试、端到端测试和正式构建通过。

月度双面生成、正反面实时预览、整份换题及成对打印导出已接入。实现与验证说明见 `number-sense.md`。
