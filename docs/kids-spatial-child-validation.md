# 空间探究旅程：儿童现场验证记录

技术验收已完成。此表用于发布前的真实儿童体验，不向产品探索足迹写入观察结果。

## 组织方式

- 项目负责人安排至少 5 名 5～7 岁儿童，在监护人知情陪同下体验。
- 只记录匿名编号与年龄段，不记录姓名、联系方式、录音或能力评分。
- 给出“可以看看这座岛”的简单邀请，观察儿童能否找到第一步；记录成人介入的位置与原因。
- 至少体验石阶岛三幕与第二座岛，允许随时停止。
- 用不同真实触屏设备核对拖动、旋转、声音和观察手册的可用性。

## 发布判断

至少 4 名同时满足前三项独立操作与关系表达条件，至少 3 名愿意继续；否则优先调整交互和引导，不扩展关卡。

当前结论：尚未开展，不能据技术测试宣称已达到儿童独立体验标准。

## 音频维护

本地音频清单与文件由 `node scripts/generate-spatial-audio.mjs` 生成。生成环境需要 Python 的 `edge-tts` 和 FFmpeg；运行网站只读取已固化的 MP3，不调用在线语音服务。修改字幕后重新生成并运行音频测试。
