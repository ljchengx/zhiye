## 定位与默认安排

面向已经熟练掌握100以内加减的孩子，以数感为核心，通过看图、圈画、比较、预测、验证与创造，理解数量、空间和变化之间的关系。

保留月度混合与A4双面。默认30份，可按实际月份生成28～31份；每份独立、随意抽取，没有阶段递进。练习纸不提供答案、解析或固定解题步骤。

儿童端建议名称“数学发现册”。每份使用具体的问题作标题，如“分给你，一共会变吗”“换个方向，还是它吗”。每面2～3个活动区，一份通常5个、允许4～6个；主要材料带2～3个关联问题，短活动通常1～2个动作。建议每面约10～15分钟，可分两次完成，最终以儿童试做调整负担。

## 六个内容方向

整月约三分之二的活动以数量关系为主目标，其余穿插空间、规律、测量与数据。按活动的主目标统计，多重标签不重复计数，不要求每天凑齐六类。

| 方向 | 重点理解 | 材料与动作 |
| --- | --- | --- |
| 数量与结构 | 不同分组、拆合、整体与部分 | 点心盘、成组物品、十格、遮挡；圈组、补画、换表示 |
| 变化与关系 | 转移、共同增减、补偿、等量替换、不变量 | 前后图、两盒、平衡图、图形线索；画箭头、判断、找依据 |
| 估计与选择 | 范围、接近程度、合理性、限制条件 | 数线、价格牌、数量条；先估、排除、比较选择 |
| 图形与空间 | 位置、平移、旋转、对称、组合与拆分 | 方格、窗户、路线、拼片；补全、配对、移动、预测 |
| 规律与推理 | 发现变化、保持规则、排除错误说法 | 图案序列、增长积木、关系链；续画、改错、造例子 |
| 测量与数据 | 统一比较标准、分类、记录、换观察角度 | 等大容器、格尺、分类图、短表格；对齐、比较、重新分类 |

每份至少包含三个方向，其中至少两个活动以数量关系为主，至少一个来自空间、规律或测量与数据。基础数数只作为读材料的准备；小数字可以用于等价、条件变化与空间推理，不通过一律加大数字制造难度。

## 一个活动怎样成立

一个活动由“材料、明确的行动、需要观察的关系”组成。主活动通常包含观察或预测、操作检查、改变一个条件再判断；这不是必须印出的固定三步标签，依据题目删去不必要步骤。

- 同一幅材料可以带几个关联小问，孩子不用反复切换背景。
- 指令、图、作答区紧邻。配对就连线，移动就画箭头，补全就在缺口处画，改数字就给紧邻说法的改写框。
- 口头解释只放在值得讨论的主任务，不让每道短题都重复写理由。
- 开放题明确哪些条件保持、允许怎样改、怎样算不同方案。如“每组一样多，换一种每组的个数”“每次选两张，每张只用一次，换顺序不算新搭配”。
- 图形必须提供数量、表示关系、限制位置、承载操作或记录结果。背景和角色不替代这些作用。

## A4双面版式

A4为210×297mm，四周12mm，可用范围186×273mm。页头24mm，页脚7mm；区块间距6mm，题内间距通常3～5mm。文字、材料和作答空间先经过测量，不以缩字号或裁切维持布局。

| 版式 | 组成与尺寸 | 使用场景 |
| --- | --- | --- |
| A 场景探索 | 主区186×150mm；下方186×80mm | 一张较大的生活或操作图带2～3问，再配一个独立活动 |
| B 混合发现 | 上方186×112mm；下方左右各90×118mm | 横向主材料，加两个需要各自绘图区的短任务 |
| C 对照推理 | 从上到下186×76、186×76、186×72mm | 前后图、关系链、长数线或表格，连续横向阅读 |

A+B通常构成一份五活动练习；也允许A+A或B+C。统一页头y=12～36mm；A的两区y=42～192、198～278；B的两行y=42～154、160～278；C的三区y=42～118、124～200、206～278；页脚y=278～285。

每面都有对应本面主材料的标题，翻面后不回指另一面的题号。编号仅作定位，按实际阅读顺序生成，不沿用旧槽位序号。追问不固定贴在区块底部；剩余空间交给明确标注的绘图和操作区域。

白底；墨蓝#24384B；主蓝#286D91；暖黄#E5B75D；浅蓝灰#EDF3F7。暖黄少量标示条件。分类与关系同时用形状、轮廓、条纹、文字或位置表达，颜色不是唯一线索。

中文使用本地Noto Sans SC，数字和算式使用Andika。儿童必须读的指令、作答标签至少14pt；活动标题16～18pt；页标题22～24pt；关键数字22～26pt；份号和日期10～11pt。

## 动画人物

使用已有Mario、Luigi、Bowser Jr、Boo和Numberblocks素材，取消小芽作为产品角色。每面通常出现1～2个角色，同一活动中同一角色始终表示同一个参与者。

- 行动者：从自己的盘子给别人点心、在地图上移动、拿预算买东西。
- 发言者：提出一个可以检验的猜想，孩子判断并检查。
- 请求帮助者：请孩子补图案、选择方案或换分法。

人物说法不总是正确；正确与错误均要有可检查的材料。Numberblocks身上的数字仅在明确表示其数量时作为数据；其他场景将“盒里有多少”等另外标注，避免混淆。人物不出现在刻度、答案框中。

## 一份完整双面样张

采用A+B，共五个活动。以下数值已检查可解，儿童纸面不印解答。

正面标题“分给你，一共会变吗？”

1. 主活动“把点心分公平”：马里奥盘中16块、路易吉盘中8块饼干，易辨识地分组并标出已知数量。圈出从左盘移到右盘的饼干，让两盘一样多；判断一共的饼干有没有变；再判断两盘各添3块后是否仍一样多，并指图说明。
2. 短活动“贴纸转个弯”：非对称3×3方格图案，明确向右转半圈，从三个不同候选中圈出转动后的图。方向、角度、转动对象均明确，正确候选唯一。

反面标题“换一种搭配，还够吗？”

3. 主活动“带着金币去商店”：四种物品标价18、22、26、30枚金币，预算48枚。每次买两种不同物品，正好用完，找两种搭配；若每件都便宜2枚，原来的两种搭配各剩几枚？不重新加全部价格，口头解释。
4. 短活动“哪一行多了一个”：显示“△＋○＝19”和“△＋△＋○＝28”。圈出多出来的图形，填写图形代表的数。允许遮挡、比较、试数，不预印代数推导。
5. 短活动“积木往两边长”：给出3、5、7块的排列，明确“每次两端各添一块”。画下一幅，再换一种摆法，块数不变。图案规则明确，新的摆法按数量与规则验收。

## 月度变化机制

先按能力和认知动作配活动，再选情境与人物，最后选版式。换角色、物品或数字不单独算新的思考任务。

建立约15个主活动家族：重组数量、分配与余量、整体与部分、单向转移、共同变化、补偿与相等、估计定位、预算选择、图形未知量、分类统计、统一单位、位置路线、拼合拆分、旋转对称、规则变化。每份两面各有一个主活动，30份共约60个主活动，同一家族约四次，再次出现时改变条件、求问或操作。短活动另外参与整月能力平衡。

正反面的主材料不同；相邻两份不重复同一主活动家族组合。每份至少一次条件改变后的重新判断、一次允许不同成立方案的操作或表达。同一面不堆叠实质相同的“谁更近”“再比较一次”。角色、选项位置不暗示答案。

单份换题保持能力组合、预计负担和主题方向，替换实际材料及条件；整月导出使用换题后的版本。

以下30份为交错主题草案，不是难度顺序。每份另配不同方向短活动。

## 数学与内容验收

整数数据、结果及中间量保持0～100。分组允许圈画、摆放、重复相加，不要求乘除口诀。测量使用明确单位与相同标准；初版不引入小数、复杂换算或依赖生活常识猜答案的题。

封闭题验证唯一解或全部并列项。开放题验证成立条件，要求两种方案时必须存在两种。规律题说明规则，或明确接受不同且可解释的规则，不能把一种可能续法当唯一答案。

空间图从几何数据生成，验证旋转、镜像、拼合与候选项。积木遮挡要提供足够视图或结构条件；信息不足不能硬判唯一块数。用于估量的线、条、图形比例必须与数据一致。

不提前画出完成后的分组、搬移结果或正确连线。内部答案、解析和解题路径不得进入儿童排版文档。

## 实施顺序

1. 整理上次中断的改动，恢复可运行基线。当前领域对象仍以八个独立任务为单位，布局仍有旧槽位；不能将文档里提前更新的描述当成完成证据。
2. 先做三份完整双面样张：转移与选择、分类与测量、图形变换与未知量。覆盖三版式，审查数学条件、字体、黑白打印与作答空间，并由孩子试做。
3. 将模型改为“活动材料＋关联小问＋作答区域＋内部验题”。每份显式保存正反面活动，不依赖前四项／后四项切片。共享材料保存一次，题号按最终阅读顺序生成。
4. 补齐主活动家族与短活动，接入月度组合、语义去重和换题约束。
5. 复用共享排版文档、SVG预览、浏览器打印与PDF，保留进度、取消、失败保留旧内容、本地角色替换。
6. 至少100个种子遍历28～31份月份，验证数学、开放条件、复现、去重；检查全部模板的字体、边界、字号和图文一致。覆盖1440、1280、390px及双面切换，打印与PDF位置误差目标不超过1mm。

首轮样张通过后再铺开整月。验收优先回答：孩子是否知道怎么动手；图是否帮助理解关系；练习是否带来有价值的第二种想法。
